# Documentation Directory

This directory contains technical references, wiring diagrams, and guides for the ESP32 flight controller project.

## Documents List

- **`master-project-documentation.md`**: Complete, self-contained engineering log covering root cause analysis, live sensor benchmark results, and firmware patch rationale.
- **`wiring-guide.md`**: Step-by-step physical connection guide for I2C sensors, FlySky receiver, GPS, and ESCs.
- **`flashing-guide.md`**: Detailed instructions on flashing via `esptool.py` and compiling from source with PlatformIO.
